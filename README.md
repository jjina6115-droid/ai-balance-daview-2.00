# 밸런스 AI — 링크로 공유하면서 광장도 함께 쓰는 버전 (Netlify)

이 방법으로 올리면:
- 학생들은 **주소(링크) 하나**로 어디서든 접속해요.
- 모든 모둠의 AI가 **한 광장에 모여서** 서로의 AI와 대화할 수 있어요.
- OpenAI 키는 선생님이 웹사이트에서 넣고, **서버 저장소에만** 저장돼서 학생들은 볼 수 없어요.
- **입장 비밀번호**를 아는 사람만 사이트를 쓸 수 있어요.

준비물: GitHub 계정, Netlify 계정, OpenAI API 키

---

## 1. GitHub에 파일 올리기

1. github.com 에 가입하고 로그인해요.
2. 오른쪽 위 **+** 버튼 → **New repository** 를 눌러요.
3. Repository name에 `balance-ai` 처럼 이름을 쓰고, **Private**(비공개)을 고른 뒤 **Create repository** 를 눌러요.
4. 다음 화면에서 **uploading an existing file** 링크를 눌러요.
5. 압축을 푼 폴더를 열고, **폴더 안의 내용 전부**(`lib`, `netlify`, `public` 폴더와 `netlify.toml`, `package.json`, `README.md`)를 한꺼번에 끌어다 놓아요.
6. 아래 **Commit changes** 를 눌러요.

> 확인: 저장소 첫 화면에 `netlify.toml`이 바로 보여야 해요. 폴더 하나 안에 다 들어가 있으면 안 돼요.

## 2. Netlify에 연결하기

1. app.netlify.com 에 들어가서 **GitHub 계정으로 가입/로그인**해요.
2. **Add new project**(또는 Add new site) → **Import an existing project** → **GitHub** 를 골라요.
3. 방금 만든 `balance-ai` 저장소를 골라요. (안 보이면 Netlify가 그 저장소를 볼 수 있게 허용해 주세요.)
4. 설정은 그대로 두고 **Deploy** 를 눌러요.

## 3. 처음 설정 (OpenAI 키 · 비밀번호)

배포가 끝나면 **학생들에게 주소를 알려 주기 전에** 선생님이 먼저 `○○○.netlify.app` 주소를 열어요. "처음 설정" 화면이 나와요.

| 칸 | 넣을 것 |
|---|---|
| OpenAI API 키 | `sk-`로 시작하는 키. 서버 저장소에만 저장되고 학생 화면에는 보이지 않아요. |
| 학생 입장 비밀번호 | 학생들에게 알려 줄 비밀번호. 이 비밀번호를 아는 사람만 사이트를 쓸 수 있어요. |
| 선생님 비밀번호 | 키와 비밀번호를 바꿀 때, 광장에서 아무 AI나 내릴 때 써요. 학생에게는 알려 주지 마세요. |

- "처음 설정" 화면은 **맨 처음 한 번만** 나와요. 먼저 연 사람이 비밀번호를 정하게 되니, 배포 직후 바로 해 주세요.
- 나중에 바꾸려면 오른쪽 위 **연결 상태 버튼(초록 불)** → **선생님 설정** → 선생님 비밀번호를 넣고 키나 비밀번호를 바꿔요.
- 입장 비밀번호를 바꾸면 학생들은 다음에 쓸 때 새 비밀번호를 다시 넣어야 해요.
- 비밀번호는 4글자 이상이에요. 글자와 숫자를 섞어서 짐작하기 어렵게 정해 주세요.
- 이미 Netlify 환경변수에 `TEACHER_CODE`를 넣어 두었다면 "처음 설정" 화면이 나오지 않아요. 그때는 **선생님 설정**에 `TEACHER_CODE` 값을 넣고 키와 입장 비밀번호를 정하면 돼요.

### (선택) Netlify 환경변수

꼭 넣을 필요는 없어요. 바꾸고 싶을 때만 **Project configuration → Environment variables**에 넣고 다시 배포(Trigger deploy)해요.

| Key | Value |
|---|---|
| `OPENAI_API_KEY` | 웹사이트에서 키를 넣지 않았을 때 쓰는 키 (웹사이트에서 넣은 키가 먼저 쓰여요) |
| `PUBLISH_MIN_SCORE` | 광장에 올리는 최소 기준 충족률 % (기본 0 = 제한 없음) |
| `PUBLISH_MIN_TESTS` | 광장에 올리기 전에 0/1 기록을 마쳐야 하는 질문 수 (기본 10) |
| `OPENAI_MODEL` | 모델 (기본 gpt-5.6-luna) |

## 4. 학생들에게 나눠 주기

1. 주소와 **학생 입장 비밀번호**를 학생들에게 알려 줘요. 학생은 처음 한 번 비밀번호를 넣으면 그 기기에서는 다시 묻지 않아요.
2. 주소 이름은 Project configuration에서 바꿀 수 있어요. (예: `balance-ai-2-3.netlify.app`)

## 고치고 싶을 때

GitHub 저장소에서 `public/index.html`을 열고 연필 아이콘으로 고친 뒤 **Commit changes** 를 누르면, Netlify가 알아서 다시 배포해요. 1~2분 뒤 주소에 반영돼요.

## 알아 둘 점

- 웹사이트 파일(`public/index.html`)에는 **키가 들어 있지 않아요.** 키는 서버 저장소(Netlify Blobs `balance-ai-settings`)에만 있어서, 비밀번호를 아는 학생이 페이지 소스를 열어도 볼 수 없어요.
- 비밀번호는 그대로 저장하지 않고, 풀 수 없게 바꾼 값만 저장해요.
- 파일을 내 컴퓨터에서 바로 열면 "AI 미연결"로 나와요. AI는 Netlify에 올린 주소에서만 동작해요.
- 모둠 AI는 Netlify Blobs 저장소(`balance-ai-bots`)에, 광장 댓글은 `balance-ai-comments`에 저장돼요. 다시 배포해도 지워지지 않아요.
- 광장 목록 카드의 **💬 댓글** 버튼을 누르면 그 AI에 댓글을 달 수 있어요.
- AI 광장은 **실시간**으로 바뀌어요. 다른 모둠이 올린 AI, 새 댓글, 좋아요·대화 수가 새로고침하지 않아도 몇 초 안에 보여요. 광장 화면을 보고 있을 때만 6초마다 '바뀐 게 있는지'만 물어보고, 바뀌었을 때만 다시 불러와요. 고칠 점을 알려 주는 댓글은 **개선**에 체크해서 달고, "개선"만 모아 볼 수 있어요. 댓글은 쓴 기기와 선생님(광장의 선생님 메뉴)만 지울 수 있어요.
- 평가 질문 1개 = OpenAI 호출 1번, 대화 1번 = 호출 1번이에요. (모둠 하나가 한 차수에 질문 10개면 10번) OpenAI에서 월 사용 한도를 꼭 걸어 두세요.
- 키를 넣지 않았는데도 "OpenAI 연결됨"이 보이면, Netlify가 자체 AI Gateway로 키를 대신 넣어 준 거예요. 이때는 Netlify 크레딧이 쓰여요. 선생님 설정에서 내 키를 넣으면 내 키가 쓰여요.
- Netlify 무료 요금제의 사용량은 Netlify 화면에서 확인할 수 있어요.

## AI 훈련소 진행 순서 (7~8차시)

AI 훈련소는 한 화면에 한 단계씩 보여 줘요. 위쪽 단계 버튼(1~6)으로 언제든 앞뒤로 옮겨 다닐 수 있어요.

1. **규칙** — AI 이름, 만든 모둠, AI에게 줄 규칙을 써요.
2. **순서도** — AI가 답하기 전에 생각할 순서를 처리/판단 단계로 만들어요.
3. **질문** — 모둠이 만든 편향된 질문 10개를 쓰고 AI에게 물어봐요.
4. **기록** — 질문을 하나씩 넘기면서 답변 요약을 쓰고, 5가지 기준(관점 다양성 · 근거 제시 · 동조 방지 · 추가 질문 · 판단 존중)마다 0 또는 1을 눌러요.
5. **결과** — 평가 데이터 표를 보고 CSV로 저장하거나 표를 복사해요. CSV 첫 줄에는 "모둠명"과 모둠 이름이, 그 아래에는 한 줄에 기준 하나씩 기준 이름(A열)과 그 기준을 지킨 개수(B열)가 들어가요. AI는 고칠 점을 알려 주지 않아요. 같은 화면의 **규칙 고치기** 칸에서 규칙을 바로 고친 뒤(1단계 규칙과 같은 칸), 같은 질문으로 다음 차수 평가를 해요.
6. **올리기** — 확인 항목이 모두 채워지면 광장에 올려요.

평가 기준 문장을 바꾸려면 `lib/shared.js`와 `public/index.html` 안의 `CRITERIA` 부분을 똑같이 고치면 돼요.

## 파일 구조

```
public/index.html               학생들이 보는 웹사이트 (화면 전체)
netlify/edge-functions/api.js   /api/* 주소를 처리하는 서버 부분
lib/core.js                     OpenAI 호출, 평가 기록 확인, 키·비밀번호 설정, 권한
lib/shared.js                   안전 원칙, 순서도 전달 문장, 5가지 평가 기준
netlify.toml                    Netlify 설정
package.json                    필요한 부품(@netlify/blobs)
```
